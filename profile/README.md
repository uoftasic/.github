# UofT ASIC Team
This is the github profile of the University of Toronto ASIC Team. The team was founded with the mission of bringing practical IC Design experience to undergraduate students.

## What we do
The team works with [TinyTapeout](https://tinytapeout.com/) and uses Open Source CAD & EDA tools to design, test, and fabricate various ICs. Please check the pinned projects for some examples of designs we are working on. You can learn more about the team from our website: [uoftasic.com](https://uoftasic.com)

## Mission Statement
The ASIC Team is focused on the following objectives:
1. Creating practical IC Design Opportunities for University Students.
2. Contributing back to the Open Source Silicon Community.
3. Creating Resources for interested parties to get started with IC design.
